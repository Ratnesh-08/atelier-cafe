# L'Atelier Café — Premium React Café Template

A premium, elegant café and restaurant website template built with React, TypeScript, Vite, Tailwind CSS, and modern web technologies.

Designed for cafés, coffee shops, restaurants, bakeries, boutique food brands, and hospitality businesses that want a sophisticated online presence.

---

## ✨ Features

- Premium editorial/luxury café design
- Fully responsive across desktop, tablet, and mobile
- React + TypeScript architecture
- Vite-powered development and production builds
- Tailwind CSS styling
- Smooth scrolling with Lenis
- Framer Motion animations
- Responsive navigation and mega menu
- Hero section with cinematic imagery
- Interactive menu section
- Reservation page
- Chef profiles
- Gallery
- Customer reviews
- About page
- Contact page
- FAQ section
- Newsletter section
- Social media / Instagram section
- SEO component
- Scroll-to-top functionality
- Optimized image assets
- Lazy-loaded secondary routes
- Production-optimized homepage loading
- Modern WebP hero image
- Clean and reusable component structure

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis
- React Router
- Lucide React

---

## 📦 Requirements

Before installing the template, make sure you have:

- Node.js 18 or newer
- npm 9 or newer
- A modern web browser
- Basic knowledge of React and JavaScript/TypeScript

---
